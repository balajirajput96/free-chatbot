Free Local Chatbot

A small, dependable chatbot that runs in your browser without an API key, subscription, server, or Copilot account. It is intentionally honest about its local, rule-based capabilities.

What it does

  • Answers common greetings, help, time, date, focus, and privacy questions.
  • Stores the conversation only in this browser’s local storage.
  • Exports a plain-text transcript for your own records.
  • Works from a downloaded folder or any static hosting service.
Privacy note: This demo has no network code and never asks for a key. For advanced AI answers, connect your own provider separately; do not place credentials in this repository.
Open index.html directly. No build step required.
